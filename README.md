# TOUCHLINE

`README.md` — единственный актуальный источник истины о структуре проекта и порядке работы с ним. Если другие заметки или старые инструкции расходятся с этим файлом, ориентируйтесь на README.

## Публикуемый сайт

GitHub Pages публикует сайт из корня репозитория `chearu-stack/touchline`, ветка `master`. Push в `master` запускает GitHub Pages build and deployment.

Основные файлы лендинга:

- `index.html` — главная страница TOUCHLINE.
- `style.css` — общие стили и адаптивная верстка.
- `system.html` — системная страница.
- `promo.html` — прежний шаблон/исходник промо-страницы, используемый генератором.
- Изображения и QR-файлы в корне — локальные ресурсы страниц. Публикуются только те ресурсы, которые добавлены в Git.

Для обычной правки главного лендинга редактируйте `index.html` и `style.css`. При коммите добавляйте только нужные файлы явно; не используйте `git add .`, поскольку в каталоге есть локальные заметки, изображения и неотслеживаемые материалы.

Пример публикации только HTML и CSS главной страницы:

```powershell
git add -- index.html style.css
git diff --cached --stat
git commit -m "Краткое описание изменения"
git push origin master
```

После push проверьте в GitHub Actions результат запуска `pages build and deployment`. Успешный push сам по себе ещё не подтверждает успешную публикацию.

## `dist/` и генератор

`dist/` содержит копии части файлов сайта, созданные генератором. Сейчас папка не отслеживается Git, а её содержимое отстаёт от корневых файлов. GitHub Pages публикует корень репозитория, поэтому `dist/` не является текущим источником опубликованного сайта.

`build_site.py` — генератор, который читает `promo.html`, перезаписывает корневые `index.html`, `style.css` и `system.html`, а затем копирует часть файлов в `dist/`. Он способен затереть ручные изменения в корневых файлах. Не запускайте его для обычной правки или публикации лендинга. Перед использованием генератора нужно отдельно согласовать и привести его в соответствие с текущими исходниками.

Таким образом, для текущего ручного процесса исходники публикуемого лендинга — корневые `index.html` и `style.css`; `dist/` — устаревшая генерируемая копия.

## Файлы вне Git

Файлы, помеченные Git как untracked, не попадут на GitHub, пока их явно не добавить. В рабочем каталоге это, в частности, `dist/`, `build_site.py`, `agent_md.md`, локальные заметки и некоторые изображения. Добавляйте такие материалы только по отдельной необходимости.

Перед любым коммитом проверьте список файлов:

```powershell
git status --short
git diff --cached --name-only
```

Не добавляйте секреты, ключи доступа или персональные данные в публичный репозиторий.
